Ao rodar o projeto, você tem um menu com quatro opções:

Montar um prato saudável — você escolhe uma opção dentro de cada categoria (proteína, carboidrato, vegetal e bebida) e, no final, o programa calcula uma pontuação e diz se as escolhas formam um prato equilibrado ou se dá pra melhorar.
Ver dicas de alimentação saudável — uma lista de dicas simples e práticas para o dia a dia.
Fazer o quiz educativo — cinco perguntas de múltipla escolha sobre alimentação, com correção na hora e um resultado final de acordo com o número de acertos.
Sair — encerra o programa.

Nada muito complexo — usei recursos básicos como arrays, listas, if/else, switch, laços de repetição e métodos simples.
